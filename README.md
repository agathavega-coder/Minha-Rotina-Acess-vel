# 🗓️ Minha Rotina Acessível

O projeto **Minha Rotina Acessível** é uma página web desenvolvida com o objetivo de auxiliar pessoas que se beneficiam de previsibilidade, clareza e organização visual em suas rotinas diárias (como pessoas neurodivergentes, idosos ou indivíduos em reabilitação cognitiva).

## 🚀 Funcionalidades
- **Organização Clara:** Apresenta 6 atividades divididas cronologicamente ao longo do dia.
- **Previsibilidade Espaço-Temporal:** Cada atividade detalha explicitamente **o que fazer**, **quando fazer** e **onde fazer**.
- **Navegação Intuitiva:** Menu fixo no topo e suporte ao atalho *"Pular para o conteúdo principal"*.
- **Interatividade:** Botões acessíveis para marcar o dia como concluído ou imprimir a rotina.

## ♿ Boas Práticas de Acessibilidade (WCAG) Aplicadas
1. **HTML Semântico:** Utilização correta de tags como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>` para dar contexto aos leitores de tela.
2. **Contraste de Cores:** Escolha de cores com proporção de contraste adequada entre o texto e o plano de fundo.
3. **Foco Visível (Focus Ring):** Todos os elementos interativos possuem um indicador visual claro (`outline`) quando navegados via teclado (tecla `Tab`).
4. **Legibilidade:** Fontes em tamanho adequado (`1.1rem`) e espaçamento confortável entre linhas para evitar fadiga visual.

## 💡 Reflexão sobre Acessibilidade e Inclusão Digital
Desenvolver este projeto permitiu compreender que a acessibilidade na web não é apenas um "adicional", mas sim um requisito fundamental de cidadania e inclusão. Páginas sobrecarregadas de informação ou visualmente confusas podem gerar barreiras intransponíveis para pessoas com deficiências cognitivas, ansiedade ou dificuldades de atenção. 

Ao adotar uma estrutura limpa, previsível e focada em responder diretamente às perguntas fundamentais (*O que? Quando? Onde?*), promovemos a autonomia, a previsibilidade e a redução da carga cognitiva, garantindo que a tecnologia cumpra seu verdadeiro papel: incluir e facilitar a vida de todos.

## 🛠️ Como publicar no GitHub Pages
1. Crie um repositório público no GitHub com o nome `minha-rotina-acessivel`.
2. Faça o upload dos arquivos `index.html`, `style.css` e `README.md` para a branch principal (`main`).
3. Vá até as **Settings** (Configurações) do repositório.
4. No menu lateral esquerdo, clique em **Pages**.
5. Na seção *Build and deployment*, selecione a branch `main` e a pasta `/ (root)`, clique em **Save**.
6. Em poucos minutos, o link do seu site estará disponível na mesma página!
